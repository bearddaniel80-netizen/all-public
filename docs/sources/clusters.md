# Clusters

The `clusters` source exposes failure clusters generated by Aegis Prime.

Clusters represent groups of related failures that share common characteristics such as error messages, stack traces, affected components, or behavioral patterns.

Use the `clusters` source to explore, filter, and analyze failure groupings.

---

## Discover the Source

List available cluster sources:

```bash
aegis query "SHOW clusters"
```

List all registered sources:

```bash
aegis query "SHOW sources"
```

---

## Inspect the Schema

View available fields:

```bash
aegis query "DESCRIBE clusters"
```

Example:

```text
cluster_id
error_type
count
first_seen
last_seen
...
```

Actual fields may vary by Aegis version and clustering configuration.

---

## Query All Clusters

Return all cluster records:

```bash
aegis query "SELECT * FROM clusters"
```

---

## Select Specific Fields

Retrieve only the fields you need:

```bash
aegis query "SELECT cluster_id FROM clusters"
```

```bash
aegis query "SELECT error_type FROM clusters"
```

```bash
aegis query "SELECT cluster_id, error_type FROM clusters"
```

---

## Filter Results

Retrieve a specific cluster:

```bash
aegis query "SELECT * FROM clusters WHERE cluster_id = 1"
```

Retrieve only selected fields:

```bash
aegis query "SELECT error_type FROM clusters WHERE cluster_id = 1"
```

---

## Query Multiple Clusters

Use the `IN` operator to match multiple cluster identifiers:

```bash
aegis query "SELECT * FROM clusters WHERE cluster_id IN [1, 5]"
```

```bash
aegis query "SELECT error_type FROM clusters WHERE cluster_id IN [1, 5]"
```

## Query Patterns

Select all fields:

```sql
SELECT * FROM clusters
```

Select specific fields:

```sql
SELECT cluster_id, error_type
FROM clusters
```

Filter by identifier:

```sql
SELECT *
FROM clusters
WHERE cluster_id = 1
```

Filter multiple identifiers:

```sql
SELECT *
FROM clusters
WHERE cluster_id IN [1, 5]
```
